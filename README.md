# Каталог аддонов Syntex

Отсюда Syntex берёт аддоны: **Аддоны → Каталог** в программе.

## Как добавить аддон

1. Положите папку аддона в корень репозитория: `manifest.json`, `main.js` и, если нужно, `styles.css`
   (как устроен аддон — в `docs/ADDONS.md` репозитория Syntex).
2. Выполните `node build-index.mjs`: он пересоберёт `index.json` по папкам.
3. Закоммитьте и отправьте изменения. Через несколько минут аддон появится в каталоге.

Новая версия аддона — это тот же путь: поднимите `version` в его `manifest.json`, пересоберите `index.json`
и отправьте. У тех, кто его поставил, рядом с аддоном появится «Обновить до …».

Аддон — это код, который работает внутри Syntex и может читать и менять заметки. Добавляйте сюда только то,
в чём уверены.

`index.json` хранит для каждого аддона `hashes` — SHA-256 его файлов (пишет `build-index.mjs`): Syntex не ставит файл,
который скачался не таким. Поэтому после любой правки аддона `index.json` нужно пересобрать.
